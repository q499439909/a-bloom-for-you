# 素材来源与处理

花卉素材来自本项目用户提供的图片序列。本仓库保存网页使用的视频和预览图；原始逐帧图片、早期源视频与 Git 历史放在独立归档中，不增加网页首屏下载量。

以 [materials.json](materials.json) 中实际记录的尺寸为准。清单逐帧保存文件名、字节数与 SHA-256，共 433 个当前源帧，不依赖旧仓库的 JPEG 或高分辨率视频来重建。

独立原图附件还保存 4 组各 40 帧的历史版本，共计 7 组、593 张 PNG。历史版本供回溯，不参与当前三朵花的构建。

## 编码与展示

- H.264 / `libx264`，30fps，`slow`，CRF 28，关键帧间隔 15，YUV420P，MP4 faststart。
- 图片按清单顺序编码，保留全部帧；浏览器按照动作定位到对应帧。
- 输出画幅保持原比例，黑色背景保留。网页当前不再进行动态背景抠除。
- 预览图取各序列第一帧，缩到网页画幅，JPEG 质量 80。
- 当前发布的视频沿用迁移前经检查的文件，总计约 1.37MB。直接从 PNG 重新编码会得到不同的压缩结果，构建报告保留参数和哈希；本次迁移没有替换页面中的花卉画面。

## 数字字体

`tools/fonts/BodoniModa.ttf` 为随仓库保存的 Bodoni Moda 字体源文件，来源为 Google Fonts 的 `ofl/bodonimoda` 目录。原许可保存在该目录的 `OFL.txt`，发布子集的许可也位于 `assets/fonts/BodoniModa-OFL.txt`。

脚本将光学尺寸固定为 32、字重固定为 400，仅保留数字、百分号、空格及等高 / 等宽数字特性，输出 `assets/fonts/bloom-numerals.woff`。源字体哈希、参数和字符集记在 `materials.json`；重建时不需要外部字体下载。

## 识别资源

`models/` 为现有 MediaPipe 手部与面部识别模型；`vendor/` 为其配套 JavaScript / WebAssembly 运行文件。原始模型、WASM 和 gzip 文件均随本仓库保存，压缩解码后须与原文件逐字节一致。

模型本体未在本次迁移中更换。素材校验入口为 `scripts/verify-assets.py`，模型下载配置为 `asset-delivery.js`。
